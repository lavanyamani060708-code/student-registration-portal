# 🎓 Student Registration & Result Portal

A responsive web-based **Student Registration & Result Portal** developed using **HTML5, CSS3, and JavaScript**.

This project allows students to enter their personal and academic information, enter subject-wise marks, and view their calculated result including total marks, percentage, and pass/fail status.

---

## 📌 Project Overview

The **Student Registration & Result Portal** is a front-end mini project designed to simplify the process of collecting student information and displaying academic results.

The system provides an easy-to-use interface where users can:

- Register student details
- Select their course and year
- Enter subject-wise marks
- Calculate total marks automatically
- Calculate percentage automatically
- Display the student's result
- Check the pass/fail status

The project is completely client-side and does not require a database or server.

---

## 🎯 Objectives

The main objectives of this project are:

- To create a simple student registration system.
- To collect and organize student information.
- To provide an easy-to-use academic marks entry form.
- To calculate total marks automatically.
- To calculate the student's percentage.
- To display the result in a structured format.
- To demonstrate front-end web development concepts.
- To create a responsive website that works on different screen sizes.

## ✨ Features

### 👨‍🎓 Student Registration

The application allows students to enter:

- Full Name
- Register Number
- Email Address
- Phone Number
- Course
- Year of Study

### 📚 Academic Details

Students can enter marks for different subjects.

### 🧮 Automatic Result Calculation

The application automatically calculates:

- Total Marks
- Percentage
- Result Status

### ✅ Form Validation

The application validates the entered information before displaying the result.

### 📱 Responsive Design

The website is designed to work on:

- Desktop
- Laptop
- Tablet
- Mobile devices

### 🎨 User-Friendly Interface

The portal provides a clean and simple interface that makes it easy for students to enter their information.
